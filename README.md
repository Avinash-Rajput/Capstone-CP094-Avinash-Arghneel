# CopyCheck - Text Similarity and Plagiarism Detection

A menu-driven Java console application that compares two or more text submissions and reports how similar each pair is.

## How to run

You need JDK 17 or newer.

```bash
./run.sh      # build and start the app   (Windows: run.bat)
./test.sh     # build and run the tests   (Windows: test.bat)
```

More documentation will be added as the project grows.
